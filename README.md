# One Emoji, One Smile

**Entry:** 🫶 (heart hands)

## The emoji

A single emoji: 🫶 — two hands shaping a heart.

## Why this one

- **Warm at first glance.** Heart hands are a gesture *made for* someone: they
  say "warmth, sent your way" with no words and no context needed. A stranger
  glancing at a phone screen reads kindness instantly.
- **Universal.** No language, no in-joke, no irony. Hands forming a heart are
  understood by any age and any background the same way.
- **Chosen, not default.** The plain smiley 😊 is the first face everyone
  reaches for; a sunflower 🌻 is pretty but says nothing *to* a person; a
  face with hearts 🥰 leans affectionate, which reads oddly from a stranger.
  Heart hands feel deliberately picked for the moment.
- **Right for a stranger.** Friendly and open, with no intimacy, sarcasm or
  flirtation — exactly the kind of warmth a stranger can welcome.

## How to run

```sh
python3 main.py
```

This writes exactly one emoji (and nothing else) to `/output/entry.txt`.
Pure Python standard library, no dependencies.
